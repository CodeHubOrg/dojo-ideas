# Dojo Ideas

This is a repository of ideas for running online and in-person
[CodeHub](https://www.codehub.org.uk/) dojos, including formats, activities, and
best practices as well as actual problems and solutions encountered during
actual dojos.

The problems are gathered in the `problems` directory, with each problem having
its own subdirectory that contains the problem description, in its own README.md
file, any relevant resources such as test files, and solutions from previous
teams if available.
